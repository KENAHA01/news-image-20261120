# Sum up 20 November's world news in one image

[![make.fun](https://make.fun/badge/news-image-20261120.svg)](https://make.fun/bounty/news-image-20261120)

Entry for the [make.fun bounty news-image-20261120](https://make.fun/bounty/news-image-20261120):
a program that draws one newspaper front-page image summing up Friday
20 November 2026 world news to `/output/entry.png`.

The front page follows the formula that won the highest dev score in the
sister contest news-image-20261119: a big serif masthead with the date, a
region bar, a strip of six big numbers, four large illustrated lead cards,
eight medium illustrated cards, a world map with numbered pins, and a list
of compact one-line titles for the remaining stories. 45 verified stories.
Every picture on the page is drawn with Pillow code in `make_image.py`
(flat cartoon style, no outside images, no AI pictures). A DATE CHECK strip
names the near-miss stories left out because they belong to 19 November or
earlier. Every story was checked against its source for the 20 November
date. See `sources.json` for one source and note per story.
